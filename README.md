# Workshop Feedback Collector

A simple and interactive web application designed to collect student feedback after workshops. Students can share their experience, rate the workshop, and provide suggestions through an easy-to-use interface.

## 🌐 Live Demo

https://final-nu-inky.vercel.app/

## 📌 Project Overview

The Workshop Feedback Collector allows workshop participants to submit feedback digitally. It provides an organiser dashboard to review submitted feedback and understand student satisfaction.

The project aims to make workshop feedback collection easier, faster, and more organised.

## ✨ Features

- Student feedback submission
- Anonymous feedback option
- 1–5 star rating system
- Written feedback and comments
- Quick feedback options
- Organiser dashboard
- Feedback and rating summary
- Responsive user interface

## 🛠️ Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling and layout
- **JavaScript** – Form interactions and functionality
- **Vercel** – Website deployment

1. Clone the repository:

```bash

```

2. Open the project folder:

```bash
cd Final
```

3. Open `index.html` in your browser or use the VS Code Live Server extension.

## 📊 How It Works

1. Students open the workshop feedback website.
2. They enter their name or select the anonymous option.
3. They provide a rating between 1 and 5 stars.
4. They submit their comments or suggestions.
5. The organiser can review the collected feedback through the dashboard.
